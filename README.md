# lttm - london terminal train map

an interactable terminal based map of london's rapid transit system.

written in python and uses [TfL's free apis](https://api-portal.tfl.gov.uk/apis) for data such as status of each line and their stations.

currently covers areas such as the tube lines, liz line, overground, dlr and tramlink
## usage

1. download uv 
2. `uv sync`
3. activate venv
